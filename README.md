## Standardized Distribution Algorithm and Why
 - Why
   - Using this algorithm to add in junk text allows the cipher to be more robust in how an attacker can analyze the cipher text as with most affine ciphers the distribution is just shifted a number over resulting in the most common English letters having the same distribution just at a different point in the alphabet ("e" is the most common but in an example encrypted message "r" is now the most common which leads an attacker to recognize the pattern and be able to crack the cipher more easily)
